TCP 延迟代理 慢链路下“上传结束却收不到回执”复现工具

延迟自代理读到字节起算，连续数据流水发送（不按块累加等待）；每向应用缓冲 ≤ 64 KiB，满则暂停该向读取；单向 EOF 先冲刷待发字节再转发半关闭，反向继续到结束。

抓取开关

每连接待写缓冲 ≤ 64 KiB、轨迹 ≤ 1 MiB；落盘变慢/超限/写盘失败时上传与回执照常，轨迹标记不完整并说明原因。正常连接等轨迹写完才显示为完整；断连或停机留下的轨迹不会被误标为完整。
